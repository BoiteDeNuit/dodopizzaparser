# dodopizzaparser
Telegram-бот с интегрированным Web-приложением, которое отображает актуальное меню, цены, наличие и фотографии товаров из сети пиццерий dodopizza.ru. Данные автоматически обновляются через «человекоподобный» парсинг сайта с использованием полноценного браузера (undetected‑chromedriver)
